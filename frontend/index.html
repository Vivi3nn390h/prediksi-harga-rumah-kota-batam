Bagaimana Cara Kerjanya?

Tiga langkah mudah untuk mendapatkan estimasi nilai pasar properti Anda

1

Input Spesifikasi Rumah

Masukkan 6 karakteristik rumah meliputi Luas Tanah, Luas Bangunan, Jumlah Kamar Tidur, Kamar Mandi, Lantai, dan Zona Lokasi.

2

Feature Engineering & Inference

Sistem secara otomatis menghitung rasio ruangan, rasio bangunan, melakukan one-hot encoding lokasi, dan meneruskannya ke pipeline model.

3

Hasil Estimasi Rupiah

Model mengembalikan estimasi harga dalam Rupiah lengkap dengan estimasi harga per m² tanah dan rentang wajar (MAE).

Batasan & Ruang Lingkup Sistem

Website ini dibangun khusus sebagai media implementasi penelitian akademik skripsi untuk menguji performa algoritma Machine Learning pada pasar properti Kota Batam.

  • Bukan merupakan platform marketplace properti (tidak menyediakan fitur iklan, transaksi jual-beli, atau chat agen).
  • Prediksi dihasilkan berdasarkan pola historis dari 3.150 data rumah bersih di 8 kecamatan Batam.
  • Nilai prediksi berbentuk estimasi statistik dan tidak menggantikan appraisal resmi profesional.
